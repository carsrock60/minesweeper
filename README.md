# Aquifer
 
A clean, modern Minesweeper experience. Simple to learn, challenging to master.
 
## Version 1 — Core Features
 
Aquifer's first release focuses on delivering the classic Minesweeper experience with responsive controls and precise timing.
 
### Game Modes
- **Easy:** 9 × 9 board with 10 mines.
- **Medium:** 16 × 16 board with 40 mines.
- **Hard:** 30 × 16 board with 99 mines.
 
### Gameplay Features
- **Precision Stopwatch:** Tracks elapsed time down to the hundredth of a second (0.01s).
- **Mine Counter:** Displays the remaining unflagged mine count.
- **First-Click Safety:** The first revealed cell is guaranteed to be safe.
- **Flagging:** Mark cells you suspect contain mines.
- **Chording:** Quickly reveal surrounding cells when the number of adjacent flags matches the displayed number. Activated by clicking the square which has all its flags placed.
 
### Version 1 Goals
- Responsive and intuitive interface.
- Accurate and reliable game logic.
- Smooth, immediate interactions.
- A polished experience across desktop and mobile devices.
